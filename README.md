# StyleMate-AI 👗

### AI-Powered Fashion Styling & Digital Wardrobe Application

StyleMate-AI is an Android-based fashion application designed to help users organize their clothing collections, explore fashion, and receive intelligent outfit recommendations. The application aims to combine Artificial Intelligence with digital wardrobe management to provide a personalized fashion experience.

## ✨ Key Features

### Currently Implemented
- **Splash Screen:** Custom StyleMate branding and design.
- **Home Screen:** Fashion-focused home interface.
- **Bottom Navigation:** Navigation between Home, Explore, Wardrobe, Planner, and Profile.
- **Digital Wardrobe:** Add clothing items with images and categories.
- **CRUD Operations:** Add, view, edit, and delete wardrobe items.
- **Category Filtering:** Organize clothing into Tops, Bottoms, Dresses, Shoes, and Accessories.
- **Search:** Search wardrobe items by name or category.
- **Local Data Storage:** Save wardrobe information using SharedPreferences.

### Planned Features
- **AI Clothing Classification:** An independently trained deep learning model to identify clothing categories from images.
- **AI Fashion Assistant:** Gemini API integration for personalized fashion advice and outfit suggestions.
- **Outfit Planner:** Plan outfits for different occasions.
- **Firebase Authentication:** Secure user registration and login.
- **Cloud Database:** Firebase Firestore integration.
- **Cloud Storage:** Firebase Storage for clothing images.
- **User Profile:** Personalized user information and preferences.
- **Explore Fashion:** Enhanced fashion discovery experience.

## 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/Misbah1l/StyleMate-AI.git
   ```

2. Open Android Studio.

3. Select **Open** and choose the cloned `StyleMate-AI` folder.

4. Allow Gradle synchronization to complete.

5. Connect an Android device or start an emulator.

6. Click **Run** to launch the application.
